# Welcome to Project Nova

## Introduction
Project Nova is an open-source task automation tool designed to help developers manage their daily workflows. It is built entirely using Python and FastAPI. Our goal is to make developer lives easier by reducing repetitive tasks.

## Local Setup and Installation
To set up Project Nova on your local computer, please follow these exact steps:
1. Clone the repository using the command: `git clone https://github.com/example/nova.git`
2. Navigate into the project folder using your terminal.
3. Install the required dependencies by running: `pip install -r requirements.txt`
4. Start the local development server by executing: `python main.py`
The server will run on port 8000 by default.

## Submitting a Pull Request
We love contributions from the community! When you are ready to submit a Pull Request (PR), please follow these guidelines:
- Always create a new branch from `main` using the naming convention: `feature/your-feature-name`.
- Before committing, ensure your code passes all linting checks by running `flake8`.
- Write unit tests for any new features.
- Submit the PR to the `main` branch. A project maintainer will review your code within 48 hours.
